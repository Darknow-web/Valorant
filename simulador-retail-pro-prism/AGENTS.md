# Reglas del Proyecto (Retail Pro Simulator)

- **Reutilización y Consistencia Visual (Pantallas):** Cada vez que se requiera utilizar una pantalla o vista que ya ha sido configurada en módulos anteriores (como el Menú Principal, Punto de Venta, Registro, etc.), se debe reutilizar la pantalla exacta que ya está construida. 
- **Preservación de Estilos:** Se deben mantener exactamente los mismos tamaños de fuentes, dimensiones de barras (top/bottom), tamaños de íconos, márgenes, colores y cualquier otro ajuste visual previamente refinado. No se deben reconstruir o alterar ligeramente estas pantallas al crear nuevos módulos, para asegurar la continuidad y facilitar el avance.
